## 🖐 5 Hands-On Exercises — Platform Engineering Use Cases

### 1. Sort Kubernetes pods by CPU usage

**Scenario:** You're triaging a noisy namespace and want to sort a list of Kubernetes pods by CPU usage, highest first, so you can spot the biggest resource hogs immediately.

```python
pods = [
    {"name": "api-gateway-7f9c", "cpu_usage_percent": 42},
    {"name": "auth-service-2b1a", "cpu_usage_percent": 87},
    {"name": "cache-redis-9d3e", "cpu_usage_percent": 15},
    {"name": "worker-queue-5a2f", "cpu_usage_percent": 63},
]

# lambda picks the field sorted() should compare on; reverse=True gives highest-first
sorted_pods = sorted(pods, key=lambda pod: pod["cpu_usage_percent"], reverse=True)

for pod in sorted_pods:
    print(f"{pod['name']}: {pod['cpu_usage_percent']}%")
# Output:
# auth-service-2b1a: 87%
# worker-queue-5a2f: 63%
# api-gateway-7f9c: 42%
# cache-redis-9d3e: 15%
```

**Why it matters:** `key=lambda ...` is the standard idiom for sorting lists of dicts/objects in Python without writing a separate named function — exactly what you need when triaging pods, nodes, or any list of resources by a metric.

### 2. Filter unhealthy cloud resources

**Scenario:** You pulled a list of cloud resources (EC2 instances, load balancers, RDS databases) and want to filter it down to only the ones currently reporting an unhealthy status, so the on-call engineer knows exactly what to check.

```python
resources = [
    {"id": "i-0a1b2c3d", "type": "ec2", "status": "healthy"},
    {"id": "i-0e4f5g6h", "type": "ec2", "status": "unhealthy"},
    {"id": "rds-prod-01", "type": "rds", "status": "healthy"},
    {"id": "lb-web-03", "type": "elb", "status": "unhealthy"},
]

# filter() keeps only the items where the lambda returns True
unhealthy = list(filter(lambda r: r["status"] == "unhealthy", resources))

for r in unhealthy:
    print(f"{r['id']} ({r['type']}) needs attention")
# Output:
# i-0e4f5g6h (ec2) needs attention
# lb-web-03 (elb) needs attention
```

**Why it matters:** `filter()` + `lambda` is a quick, readable way to shrink a large resource inventory down to just the items that need action, without writing a full `for` loop with an `if` and an `append`.

### 3. Lambda as a callback for pipeline events

**Scenario:** Your CI/CD runner fires named events (`build_started`, `build_success`, `build_failed`) and you want a small dispatch table of callbacks to react to each one, without defining a full function for every single event.

```python
# A small dispatch table mapping pipeline events to inline lambda handlers
event_handlers = {
    "build_started": lambda job: print(f"[{job}] Build started..."),
    "build_success": lambda job: print(f"[{job}] Build passed, triggering deploy."),
    "build_failed": lambda job: print(f"[{job}] Build failed! Notifying on-call."),
}

def run_pipeline(job_name, event):
    handler = event_handlers.get(event, lambda job: print(f"[{job}] Unknown event."))
    handler(job_name)

run_pipeline("checkout-service", "build_started")
run_pipeline("checkout-service", "build_success")
run_pipeline("checkout-service", "build_failed")
# Output:
# [checkout-service] Build started...
# [checkout-service] Build passed, triggering deploy.
# [checkout-service] Build failed! Notifying on-call.
```

**Why it matters:** Lambdas make great lightweight callbacks/handlers for event-driven code like webhook dispatchers or pipeline hooks, where each handler is one line and doesn't deserve its own `def`.

### 4. Custom priority order for incident severity

**Scenario:** You have a list of open incidents and need to sort them by severity in a specific operational priority order (`critical` → `high` → `medium` → `low`) — plain alphabetical sorting would get this wrong.

```python
incidents = [
    {"id": "INC-102", "severity": "medium"},
    {"id": "INC-098", "severity": "critical"},
    {"id": "INC-110", "severity": "low"},
    {"id": "INC-105", "severity": "high"},
]

# Define the priority order we actually care about (not alphabetical!)
priority_order = ["critical", "high", "medium", "low"]

# lambda looks up each incident's position in our custom priority list and sorts on that
sorted_incidents = sorted(incidents, key=lambda inc: priority_order.index(inc["severity"]))

for inc in sorted_incidents:
    print(f"{inc['id']} - {inc['severity']}")
# Output:
# INC-098 - critical
# INC-105 - high
# INC-102 - medium
# INC-110 - low
```

**Why it matters:** Combining `lambda` with `list.index()` inside `sorted()` lets you sort by any custom order you define — perfect for severity levels, environment tiers (`prod` > `staging` > `dev`), or deployment stages that don't sort correctly alphabetically.

### 5. Convert a list of memory values with map

**Scenario:** A monitoring script reports container memory usage in MiB, but your dashboard needs GiB. You want to convert the whole list in one line.

```python
memory_usage_mib = [512, 1024, 2048, 4096, 256]

# map() applies the lambda to every value in the list; 1 GiB = 1024 MiB
memory_usage_gib = list(map(lambda mib: round(mib / 1024, 2), memory_usage_mib))

print(memory_usage_gib)
# Output: [0.5, 1.0, 2.0, 4.0, 0.25]
```

**Why it matters:** `map()` + `lambda` is the go-to pattern for transforming every value in a list of metrics (units, timestamps, currency) in a single, readable expression instead of a manual loop.

## 🔹 What is a `lambda` function?

A `lambda` is a **short, anonymous function** defined with the `lambda` keyword.
It’s mainly used for **quick, throwaway functions** — especially when passing logic as a parameter.

---

### ✅ Syntax:

```python
lambda arguments: expression
```

## ✅ Example 1: Double a number (like doubling a grocery price)

🔸 Use case: You want to quickly double a number (like doubling the price of a grocery item when you buy two)

```python
double = lambda x: x * 2
print(double(5))  # Output: 10
```

## ✅ Example 2: Sort customer names by their length

🔸 Real use: Sort a list of customer names based on how long the name is.

```python
names = ["Milo", "Ana", "Jonathan", "Sam", "Priya"]
sorted_names = sorted(names, key=lambda name: len(name))
print(sorted_names)  # Output: ['Ana', 'Sam', 'Milo', 'Priya', 'Jonathan']
```

## ✅ Example 3: Filter even quantities

🔸 Real use: Select the even-numbered quantities from a shopping cart (e.g., how many of each item you're buying)

```python
quantities = [1, 2, 3, 4, 5, 6]
even_quantities = list(filter(lambda x: x % 2 == 0, quantities))
print(even_quantities)  # Output: [2, 4, 6]
```

## ✅ Example 4: Apply tax to grocery prices

🔸 Real use: You're given a list of grocery prices, and you want to apply a 10% sales tax.

```python
prices = [100, 200, 300]
final_prices = list(map(lambda x: x * 1.1, prices))
print(final_prices)  # Output: [110.0, 220.0, 330.0]
```

## ✅ Example 5: Ternary logic using lambda (free shipping check)

🔸 Real use: Checking whether a customer's order total qualifies for free shipping.

```python
check_shipping = lambda total: "Free Shipping" if total >= 50 else "Shipping Fee Applies"
print(check_shipping(75))  # Output: Free Shipping
print(check_shipping(35))  # Output: Shipping Fee Applies
```

## ✅ When to use `lambda`

| Situation                        | Use `lambda`? |
| -------------------------------- | ------------- |
| Short, one-liner function        | ✅ Yes         |
| Function used only once          | ✅ Yes         |
| You need to name and reuse logic | ❌ Use `def`   |
