## 🖐 5 Hands-On Exercises — Platform Engineering Use Cases

Real scenarios solved end-to-end so you can see sets used the way you'd actually use them on the job.

### 1. Instant firewall port allowlist check

**Scenario:** A request comes in on some port, and you need to instantly decide whether to allow it — checking against a list would get slow as the allowlist grows.

```python
allowed_ports = {22, 80, 443, 3306}   # set — O(1) membership test

def check_port(port):
    if port in allowed_ports:
        print(f"✅ Port {port} allowed")
    else:
        print(f"🔴 Port {port} blocked")

check_port(443)    # ✅ allowed
check_port(8080)   # 🔴 blocked
```
**Why it matters:** `port in allowed_ports` is O(1) with a set vs O(n) with a list — with thousands of firewall checks per second, this is not just style, it's performance.

### 2. Sync security group rules — what to add, what to remove

**Scenario:** You have the *current* attached security groups and the *desired* set (from Terraform state) and need the minimal diff to apply.

```python
current_sgs = {'web-sg', 'db-sg', 'legacy-sg'}
desired_sgs = {'web-sg', 'db-sg', 'cache-sg'}

to_add = desired_sgs - current_sgs        # in desired but not current
to_remove = current_sgs - desired_sgs      # in current but not desired

print(f"Attach: {to_add}")      # {'cache-sg'}
print(f"Detach: {to_remove}")   # {'legacy-sg'}
```
**Why it matters:** set difference (`-`) is exactly the operation behind any "reconcile desired vs actual state" logic — the core of tools like Terraform and Kubernetes controllers.

### 3. De-duplicate hostnames collected from multiple inventory sources

**Scenario:** You scrape hostnames from Ansible inventory, a CMDB export, and a manual list — with overlaps.

```python
ansible_hosts = ['web01', 'web02', 'db01']
cmdb_hosts = ['db01', 'db02', 'web01']
manual_hosts = ['cache01']

all_unique = set(ansible_hosts) | set(cmdb_hosts) | set(manual_hosts)   # union
print(sorted(all_unique))   # ['cache01', 'db01', 'db02', 'web01', 'web02']
print(f"Total unique hosts: {len(all_unique)}")
```
**Why it matters:** `set()` on a list instantly removes duplicates, and `|` (union) combines multiple sources cleanly — a common step before generating a final inventory file.

### 4. Detect configuration drift between two snapshots

**Scenario:** Compare a Terraform-managed resource list against what's actually live in the cloud to spot orphaned or missing resources.

```python
terraform_state = {'i-101', 'i-102', 'i-103'}
live_resources = {'i-102', 'i-103', 'i-104'}

orphaned = live_resources - terraform_state    # exists live, but not in state
missing = terraform_state - live_resources      # in state, but not actually live
changed = terraform_state ^ live_resources        # symmetric difference — anything that differs

print(f"Orphaned (not in Terraform): {orphaned}")   # {'i-104'}
print(f"Missing (in state, not live): {missing}")   # {'i-101'}
print(f"All drifted resources: {changed}")            # {'i-101', 'i-104'}
```
**Why it matters:** `-` and `^` (symmetric difference) are the standard building blocks of any drift-detection script.

### 5. Validate that all required services are running before a deploy

**Scenario:** Before rolling out a new version, confirm every required backing service is currently healthy.

```python
required_services = {'api', 'db', 'cache'}
running_services = {'api', 'db', 'cache', 'worker', 'scheduler'}

if required_services <= running_services:       # issubset() — is required fully covered?
    print("✅ All required services are running — safe to deploy")
else:
    missing = required_services - running_services
    print(f"🔴 Cannot deploy — missing: {missing}")
```
**Why it matters:** `<=` (subset check) is a one-line pre-deploy gate — no manual loop needed to confirm every required item is present.

Sets are a powerful yet often underutilized data structure in Python that provide essential functionality for everyday programming tasks. This comprehensive guide covers all aspects of sets with practical, easy-to-follow examples.

## **1. Set Fundamentals**

### **What is a Set?**
An unordered, mutable collection of unique, hashable elements with O(1) membership testing.

```python
# Everyday examples:
locker_numbers = {12, 45, 78, 101}  # Available lockers
class_sections = {'Section-A', 'Section-B', 'Section-C'}  # Enrollment sections
attendance_status = {'present', 'absent', 'late'}  # Valid attendance states
```

### **Key Characteristics**
- **Uniqueness**: Automatically eliminates duplicates
- **Unordered**: No positional indexing
- **Mutable**: Can add/remove items (except frozen sets)
- **High Performance**: O(1) membership tests
- **Hashable Elements**: Can only contain immutable types

## **2. Set Creation Methods**

### **Basic Creation**
```python
# Literal syntax
core_subjects = {'math', 'science', 'english'}

# From iterable
enrolled_students = set(['Amit', 'Riya', 'Sam', 'Amit', 'Riya'])  # {'Amit', 'Riya', 'Sam'}

# Empty set (note: {} creates a dict)
empty_set = set()
```

### **Set Comprehensions**
```python
# Unique class sections from student records
class_sections = {student['section'] for student in get_students()}

# Students who failed the exam
failed_students = {student['name'] for student in students if student['grade'] == 'F'}
```

## **3. Core Set Operations**

### **Membership Testing**
```python
# Check if locker number is available
if locker_number in available_lockers:
    assign_locker(locker_number)

# Check if section is valid
if chosen_section not in class_sections:
    raise ValueError(f"Unknown section: {chosen_section}")
```

### **Adding Elements**
```python
# Single element
club_members.add('Priya')

# Multiple elements
club_members.update({'Karan', 'Neha'})
```

### **Removing Elements**
```python
# Remove if exists (KeyError if missing)
club_members.remove('Rohan')

# Remove if exists (no error)
club_members.discard('maybe-member')

# Remove and return arbitrary element
next_member = club_members.pop()

# Clear all elements
club_members.clear()
```

## **4. Set Theory Operations**

### **Union (|)**
```python
# Combine members from two clubs
chess_club = {'Amit', 'Sara'}
robotics_club = {'Neha', 'Karan'}
all_club_members = chess_club | robotics_club  # {'Amit', 'Sara', 'Neha', 'Karan'}
```

### **Intersection (&)**
```python
# Find students in both clubs
science_club = {'Amit', 'Riya', 'Neha'}
math_club = {'Amit', 'Karan', 'Neha'}
shared_members = science_club & math_club  # {'Amit', 'Neha'}
```

### **Difference (-)**
```python
# Identify students still on the waiting list
signed_up = {'Amit', 'Riya', 'Sam', 'Neha'}
confirmed = {'Amit', 'Riya', 'Sam'}
still_waiting = signed_up - confirmed  # {'Neha'}
```

### **Symmetric Difference (^)**
```python
# Find changes between last week's and this week's class schedule
old_schedule = {'monday': 'math', 'tuesday': 'science'}
new_schedule = {'monday': 'math', 'wednesday': 'art'}
changed_days = set(old_schedule) ^ set(new_schedule)  # {'tuesday', 'wednesday'}
```

## **5. Set Comparison Methods**

### **Subset Checks**
```python
# Validate required subjects are being taught
required_subjects = {'math', 'science'}
taught_subjects = {'math', 'science', 'art', 'music'}

if required_subjects <= taught_subjects:  # issubset()

```

### **Superset Checks**
```python
# Check if all requested books are in the library catalog
library_catalog = {'Book A', 'Book B', 'Book C', 'Book D'}
requested_books = {'Book B', 'Book C'}

if library_catalog >= requested_books:  # issuperset()
    print("All requested books are available")
```

### **3. Roster Drift Detection**
```python
def detect_roster_drift(expected, actual):
    expected_set = set(expected.items())
    actual_set = set(actual.items())
    
    added = expected_set - actual_set
    removed = actual_set - expected_set
    
    return {
        'added': dict(added),
        'removed': dict(removed)
    }
```

# **Python Set Built-in Functions: Comprehensive Guide**

Sets are essential for everyday programming tasks involving unique collections, membership checks, and data comparisons. This guide covers all set built-in functions with practical, easy-to-follow examples.

## **1. Core Set Functions**

### **`len()` - Get Set Cardinality**
Returns the number of elements in a set.

```python
locker_numbers = {12, 45, 78, 101}
print(len(locker_numbers))  # Output: 4

# Use Case: Validate minimum club size
if len(club_members) < 3:
    notify_teacher("Club needs more members to stay active")
```

### **`set()` - Set Constructor**
Creates a set from an iterable, removing duplicates.

```python
# From list with duplicates
student_ids = ['S-101', 'S-102', 'S-101']
unique_ids = set(student_ids)  # {'S-101', 'S-102'}

# From a list of student records
all_sections = set(student['section'] for student in get_students())
```

## **2. Set Modification Methods**

### **`.add(element)` - Insert Single Element**
Adds an element to the set if not already present.

```python
club_members = {'Amit', 'Riya'}
club_members.add('Karan')

# Example: Dynamic membership
new_member = 'Priya'
club_members.add(new_member)
```

### **`.update(*iterables)` - Merge Multiple Collections**
Adds elements from one or more iterables.

```python
core_subjects = {'math', 'science'}
core_subjects.update(['art', 'music'], {'pe', 'history'})
# {'math', 'science', 'art', 'music', 'pe', 'history'}

# Use Case: Combine reading lists
required_books = get_required_books()
recommended_books = get_recommended_books()
required_books.update(recommended_books)
```

## **3. Set Removal Methods**

### **`.remove(element)` - Delete Specific Element**
Removes an element, raises KeyError if not found.

```python
enrolled_subjects = {'math', 'science', 'art'}
enrolled_subjects.remove('art')

# Example: Revoke club access
try:
    club_members.remove('graduated_student')
except KeyError:
    log.warning("Attempted to remove a member who isn't in the club")
```

### **`.discard(element)` - Remove if Exists**
Removes an element without raising an error.

```python
tracked_books = {'Dune', 'Hobbit'}
tracked_books.discard('Odyssey')  # No error

# Use Case: Safe cleanup
returned_books.discard(book_title)
```

### **`.pop()` - Remove and Return Arbitrary Element**
Removes and returns a random element, raises KeyError if empty.

```python
pending_signups = {'Amit', 'Riya', 'Sam'}
next_signup = pending_signups.pop()

# Example: Process signup queue
while signup_queue:
    current_signup = signup_queue.pop()
    process_signup(current_signup)
```

### **`.clear()` - Empty the Set**
Removes all elements.

```python
temp_group = {'guest1', 'guest2'}
temp_group.clear()  # set()

# Use Case: Reset a scratch roster
draft_roster.clear()
```

## **4. Set Operations**

### **`.union(*others)` / `|` - Set Union**
Returns a new set with elements from all sets.

```python
morning_class = {'Amit', 'Riya'}
evening_class = {'Karan', 'Neha'}
all_students = morning_class.union(evening_class)  # {'Amit', 'Riya', 'Karan', 'Neha'}
# Equivalent to:
all_students = morning_class | evening_class

# Example: Combine two friend groups
combined_friends = group_a.union(group_b)
```

### **`.intersection(*others)` / `&` - Set Intersection**
Returns elements common to all sets.

```python
chess_club = {'Amit', 'Riya', 'Sam'}
robotics_club = {'Amit', 'Karan', 'Sam'}
shared_members = chess_club & robotics_club  # {'Amit', 'Sam'}

# Use Case: Find students in both clubs
common_members = club_a.intersection(club_b)
```

### **`.difference(*others)` / `-` - Set Difference**
Returns elements in the first set but not in others.

```python
all_students = {'Amit', 'Riya', 'Sam', 'Neha'}
graduated = {'Amit', 'Neha'}
current_students = all_students - graduated  # {'Riya', 'Sam'}

# Example: Identify new members since last term
new_members = current_roster - previous_roster
```

### **`.symmetric_difference(other)` / `^` - Unique Elements**
Returns elements in either set but not both.

```python
old_timetable = {'math', 'science'}
new_timetable = {'math', 'art'}
changes = old_timetable ^ new_timetable  # {'science', 'art'}

# Use Case: Detect schedule changes
changed_subjects = old_schedule.symmetric_difference(new_schedule)
```

## **5. Set Predicate Methods**

### **`.issubset(other)` / `<=` - Subset Check**
Tests if all elements are in another set.

```python
required_subjects = {'math', 'science'}
enrolled_subjects = {'math', 'science', 'art'}
if required_subjects <= enrolled_subjects:
    print("All required subjects are covered")

# Example: Validate club eligibility
if not required_courses.issubset(completed_courses):
    block_registration("Missing prerequisite courses")
```

### **`.issuperset(other)` / `>=` - Superset Check**
Tests if all elements of another set are contained.

```python
library_catalog = {'Book A', 'Book B', 'Book C', 'Book D'}
requested_books = {'Book B', 'Book C'}
if library_catalog >= requested_books:
    print("All requested books are available")

# Use Case: Permission validation
if not teacher_permissions.issuperset(required_perms):
    deny_access()
```

### **`.isdisjoint(other)` - No Common Elements**
Returns True if sets have no elements in common.

```python
morning_class = {'Amit', 'Riya'}
evening_class = {'Karan', 'Neha'}
if morning_class.isdisjoint(evening_class):
    print("No student is enrolled in both sessions")

# Example: Schedule conflict check
if student_a_classes.isdisjoint(student_b_classes):
    log.info("No overlapping classes — safe to pair for a group project")
```

## **6. Frozen Set Functions**

### **`frozenset()` - Immutable Set Constructor**

def detect_roster_drift(registrar_list, actual_attendance):
