## 🖐 5 Hands-On Exercises — Platform Engineering Use Cases

Real scenarios solved end-to-end so you can see dict comprehensions used the way you'd actually use them on the job.

### 1. Double replica counts for a traffic-spike scaling plan

**Scenario:** You need a quick "scale for Black Friday" plan that doubles every service's current replica count.

```python
current_replicas = {'web': 3, 'api': 5, 'worker': 2}

scaled_plan = {service: count * 2 for service, count in current_replicas.items()}
print(scaled_plan)   # {'web': 6, 'api': 10, 'worker': 4}
```
**Why it matters:** transforming every value in a dict by a rule (here: `* 2`) is the classic dict comprehension use case — no separate loop or temp dict needed.

---

### 2. Normalize env var keys before exporting to a shell script

**Scenario:** Config keys come in lowercase from a YAML file, but shell env vars are conventionally uppercase.

```python
config = {'db_host': 'db.internal', 'db_port': '5432', 'log_level': 'info'}

env_vars = {k.upper(): v for k, v in config.items()}
print(env_vars)   # {'DB_HOST': 'db.internal', 'DB_PORT': '5432', 'LOG_LEVEL': 'info'}

for k, v in env_vars.items():
    print(f'export {k}="{v}"')
```
**Why it matters:** transforming keys (not just values) with `k.upper()` is a common step when bridging config formats (YAML → shell, JSON → env).

---

### 3. Filter services that are breaching their SLA

**Scenario:** You have uptime percentages per service and want just the ones below your 99.9% SLA target.

```python
uptime = {'api': 99.95, 'web': 99.80, 'db': 99.99, 'cache': 98.50}

breaching = {svc: pct for svc, pct in uptime.items() if pct < 99.9}
print(breaching)   # {'web': 99.8, 'cache': 98.5}
```
**Why it matters:** adding `if condition` to a comprehension is how you build a one-line alert-worthy subset instead of writing a full loop with an `if`/`append`.

---

### 4. Invert an HTTP status-code map for reverse lookups

**Scenario:** You have code→meaning, but a log-analysis script needs meaning→code to search for a specific error type.

```python
status_meaning = {200: 'OK', 404: 'Not Found', 500: 'Server Error', 503: 'Unavailable'}

meaning_to_code = {v: k for k, v in status_meaning.items()}
print(meaning_to_code['Server Error'])   # 500
```
**Why it matters:** swapping key↔value with `{v: k for k, v in d.items()}` is the standard one-liner for building a reverse lookup table.

---

### 5. Rank log levels by severity for sorting alerts

**Scenario:** You need to sort a batch of alerts by severity, but severity is currently just a string (`"INFO"`, `"ERROR"`, ...) — strings don't sort in the order you want.

```python
severity_rank = {level: rank for rank, level in enumerate(['DEBUG', 'INFO', 'WARNING', 'ERROR', 'CRITICAL'])}
print(severity_rank)   # {'DEBUG': 0, 'INFO': 1, 'WARNING': 2, 'ERROR': 3, 'CRITICAL': 4}

alerts = [{'msg': 'disk full', 'level': 'CRITICAL'}, {'msg': 'slow response', 'level': 'WARNING'}]
alerts.sort(key=lambda a: severity_rank[a['level']], reverse=True)
print([a['level'] for a in alerts])   # ['CRITICAL', 'WARNING']
```
**Why it matters:** building a rank dict with `enumerate()` lets you sort by a custom order instead of alphabetical — essential for any alert/log severity sorting.

Here are some practical and clean **dictionary comprehension examples** in Python — a powerful way to create or transform dictionaries in a single line.

---

### ✅ 1. **Basic Syntax**

```python
{key: value for item in iterable}
```

---

### ✅ 2. **Squares of Numbers**

```python
squares = {x: x**2 for x in range(1, 6)}
print(squares)
```

#### 🖨️ Output:

```python
{1: 1, 2: 4, 3: 9, 4: 16, 5: 25}
```

---

### ✅ 3. **Uppercase Keys**

```python
data = {'env': 'dev', 'owner': 'deepak'}
upper_keys = {k.upper(): v for k, v in data.items()}
print(upper_keys)
```

#### 🖨️ Output:

```python
{'ENV': 'dev', 'OWNER': 'deepak'}
```

---

### ✅ 4. **Filter Items in a Dict (e.g., only values > 50)**

```python
marks = {'Math': 90, 'English': 45, 'Science': 80}
passed = {k: v for k, v in marks.items() if v >= 50}
print(passed)
```

#### 🖨️ Output:

```python
{'Math': 90, 'Science': 80}
```

---

### ✅ 5. **Swap Keys and Values**

```python
original = {'a': 1, 'b': 2, 'c': 3}
swapped = {v: k for k, v in original.items()}
print(swapped)
```

#### 🖨️ Output:

```python
{1: 'a', 2: 'b', 3: 'c'}
```

---

### ✅ 6. **Turn a Dict into a List of Field/Value Records**

```python
profile = {'Name': 'Asha', 'Age': 28, 'City': 'Pune'}
records = [{'Field': k, 'Value': v} for k, v in profile.items()]
print(records)
```

#### 🖨️ Output:

```python
[{'Field': 'Name', 'Value': 'Asha'}, {'Field': 'Age', 'Value': 28}, {'Field': 'City', 'Value': 'Pune'}]
```

---

### ✅ 7. **Word Lengths from a Sentence**

```python
sentence = "Python is fun"
length_map = {word: len(word) for word in sentence.split()}
print(length_map)
```

#### 🖨️ Output:

```python
{'Python': 6, 'is': 2, 'fun': 3}
```
