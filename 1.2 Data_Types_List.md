### 1. Rolling update — process a deploy queue one instance at a time

**Scenario:** You're rolling out a new AMI across a fleet, one instance at a time, so you don't take everything down together.

```python
instances = ['i-101', 'i-102', 'i-103']

while instances:
    current = instances.pop(0)      # take the first instance off the queue
    print(f"Updating {current}...")
    # update_instance(current) would go here
    print(f"{current} done. {len(instances)} remaining.")
```
**Why it matters:** `pop(0)` + `while` is the standard pattern for draining a work queue safely, one item at a time.

### 2. Filter unhealthy pods from a status list

**Scenario:** You have pod statuses pulled from `kubectl` and want just the ones that need attention.

```python
pod_statuses = [
    {"name": "web-1", "status": "Running"},
    {"name": "web-2", "status": "CrashLoopBackOff"},
    {"name": "db-1", "status": "Running"},
    {"name": "cache-1", "status": "Pending"},
]

unhealthy = [p["name"] for p in pod_statuses if p["status"] != "Running"]
print(unhealthy)   # ['web-2', 'cache-1']
```
**Why it matters:** list comprehensions with a filter condition are how you'd write a one-line health-check alert generator.

### 3. Batch API calls to avoid rate limits

**Scenario:** Cloud APIs (AWS, GCP) often cap how many resource IDs you can pass per call. You need to chunk a big instance list into batches of 10.

```python
instance_ids = [f"i-{n:04d}" for n in range(1, 26)]   # 25 fake instance IDs

def batch(items, size):
    for i in range(0, len(items), size):
        yield items[i:i + size]

for chunk in batch(instance_ids, 10):
    print(f"Calling API with batch: {chunk}")
    # ec2.describe_instances(InstanceIds=chunk)
```
**Why it matters:** slicing (`items[i:i+size]`) is the core trick behind every "process in batches" script you'll write against a rate-limited API.

### 4. Detect config drift between desired and running instance types

**Scenario:** You want to compare the instance types Terraform expects against what's actually running, and flag anything unexpected.

```python
desired_types = ['t3.medium', 't3.medium', 'm5.large']
running_types = ['t3.medium', 'm5.large', 'm5.large']

# dedupe + sort both sides for a clean comparison
desired_unique = sorted(set(desired_types))
running_unique = sorted(set(running_types))

print(f"Desired: {desired_unique}")
print(f"Running: {running_unique}")

if desired_unique != running_unique:
    print("🔴 Drift detected between desired and running instance types")
else:
    print("✅ No drift")
```
**Why it matters:** `sorted(set(...))` is a quick way to normalize two lists before comparing them for infra drift.

### 5. Pair instances with their availability zones

**Scenario:** You have two parallel lists (instance IDs and AZs, e.g. from a CSV export) and need to combine them for a report.

```python
instance_ids = ['i-123', 'i-456', 'i-789']
azs = ['us-east-1a', 'us-east-1b', 'us-east-1c']

for instance, az in zip(instance_ids, azs):
    print(f"{instance} is in {az}")

# Build a report as a list of dicts
report = [{"instance": i, "az": a} for i, a in zip(instance_ids, azs)]
print(report)
```
**Why it matters:** `zip()` is the standard way to combine two related lists that come from separate sources (e.g. two CSV columns) without manual indexing.

Lists are one of Python's most versatile and frequently used data structures, especially useful for managing everyday collections like shopping lists, recipes, and to-do items. This guide covers lists in exhaustive detail with practical, easy-to-follow examples.

## **1. List Fundamentals**

### **What is a List?**
An ordered, mutable collection of elements that can contain mixed data types.

```python
# Everyday examples:
grocery_items = ['apples', 'bread', 'milk']       # weekly shopping list
recipe_tags = ['vegetarian', 'gluten-free', 'quick-meal']  # recipe categories
```

### **Key Characteristics**
- **Ordered**: Maintains insertion order
- **Mutable**: Can be modified after creation
- **Indexable**: Access elements by position (0-based)
- **Heterogeneous**: Can mix data types (though uncommon in a typical grocery list)

## **2. List Creation Methods**

### **Basic Creation**
```python
# Empty list for dynamic population
shopping_cart = []

# Pre-populated list
stores = ['Farmers Market', 'Corner Grocery', 'Bulk Foods Co-op']
```

### **Using `list()` Constructor**
```python
# Convert tuple to list
fruit_types = list(('apple', 'banana', 'orange'))

# Convert string to list of chars
recipe_name = list('lasagna')
```

### **List Comprehension (Common Pattern)**
```python
# Generate list of even aisle numbers
aisles = [aisle for aisle in range(1, 24) if aisle % 2 == 0]

# Extract item names from a grocery receipt
items = [line['item_name'] for line in receipt['line_items']]
```

## **3. List Operations**

### **Accessing Elements**
```python
stores = ['Farmers Market', 'Corner Grocery', 'Bulk Foods Co-op']
print(stores[0])   # 'Farmers Market'
print(stores[-1])  # 'Bulk Foods Co-op' (last element)
```

### **Slicing (Extracting Subsets)**
```python
all_prices = [2, 4, 6, 12, 15, 20]
mid_prices = all_prices[1:3]    # [4, 6]
high_prices = all_prices[3:5]     # [12, 15]
last_three = all_prices[-3:]   # [12, 15, 20]
last_price = all_prices[-1]         # 20
print("Mid Prices:", mid_prices)
print("High Prices:", high_prices)
print("Last Three Prices:", last_three)
print("Last Price:", last_price)
print("All Prices:", all_prices)
```

## **4. List Methods for Everyday Tasks**

### **Essential Methods**
| Method | Description | Example |
|--------|-------------|----------------|
| `append()` | Add single item | `shopping_list.append(new_item)` |
| `extend()` | Merge lists | `full_list.extend(new_items)` |
| `insert()` | Add at index | `todo_list.insert(0, 'urgent-task')` |

| `sort()` | In-place sort | `item_prices.sort()` |
| `reverse()` | Reverse order | `recipe_steps.reverse()` |
| `copy()` | Shallow copy | `backup_list = original_list.copy()` |

## **7. Lists vs Other Data Structures**

### **When to Use Lists**
- **Order matters** (recipe steps, chore sequences)
- **Need modification** (dynamic shopping lists)
- **Mixed operations** (adding/removing/accessing)

### **When to Avoid Lists**
- **Frequent membership tests** (use sets)
- **Key-value pairs** (use dictionaries)
- **Immutable data** (use tuples)

## **8. Performance Considerations**

### **Time Complexity**
| Operation | Complexity | Impact |
|-----------|------------|---------------|
| Index access | O(1) | Fast item lookups |
| Append | O(1) | Efficient list building |
| Insert | O(n) | Costly for large lists |
| Search | O(n) | Slow for large inventories |

### **Optimization Example**
```python
# Convert to set for faster lookups (when order doesn't matter)
allowed_items = {'apples', 'bread', 'milk', 'eggs'}
if item in allowed_items:  # O(1) lookup
    add_to_cart(item)
```

# **Python List Built-in Functions: Comprehensive Guide with Examples**

Lists are fundamental to Python programming, used for managing everyday collections like shopping lists, recipes, and to-do items. This guide covers all built-in list functions with practical, easy-to-follow examples.

---

## **1. Core List Functions**

### **`len()` - Get List Length**
Returns the number of items in a list.

```python
items = ['apples', 'bread', 'milk']
print(len(items))  # Output: 3

# Use Case: Validate minimum items before checkout
if len(items) < 2:
    add_more_items()
```

### **`list()` - Create New List**
Constructs a list from an iterable.

```python
# Convert a recipe's ingredient dictionary to a list of keys
recipe = {'Name': 'Pancakes', 'Category': 'Breakfast'}
recipe_keys = list(recipe.keys())  # ['Name', 'Category']

# Convert daily step-count readings
step_counts = list(get_daily_step_counts())
```

---

## **2. List Manipulation Functions**

### **`append()` - Add Single Item**
Adds an item to the end of the list.

```python
shopping_list = ['bread', 'milk']
shopping_list.append('eggs')
# ['bread', 'milk', 'eggs']

# Example: Building a shopping list section by section
new_items = []
for section in ['Produce', 'Dairy']:
    item = pick_item(section)
    new_items.append(item)
```

### **`extend()` - Merge Lists**
Adds all elements of an iterable to the list.

```python
base_list = ['bread', 'milk']
additional_items = ['cheese', 'juice']
base_list.extend(additional_items)
# ['bread', 'milk', 'cheese', 'juice']

# Use Case: Combine shopping lists from multiple family members
all_items = []
for person in ['Alex', 'Jamie']:
    persons_items = get_items(person)
    all_items.extend(persons_items)
```

### **`insert()` - Add Item at Index**
Inserts an item at a specific position.

```python
recipe_steps = ['chop', 'cook', 'serve']
recipe_steps.insert(1, 'season')
# ['chop', 'season', 'cook', 'serve']

# Example: Priority chores
chores = ['dust', 'mop']
chores.insert(0, 'urgent-spill-cleanup')  # Highest priority
```

## **3. List Access Functions**

### **`index()` - Find Item Position**
Returns the index of the first matching item.

```python
prices = [2, 5, 8, 12]
target_index = prices.index(8)  # 2

# Use Case: Locate a mispriced item
try:
    bad_index = items.index('mispriced-item')
    fix_price(bad_index)
except ValueError:
    print("Item not found")
```

### **`count()` - Count Occurrences**
Returns the number of times an item appears.

```python
statuses = ['delivered', 'pending', 'delivered', 'delivered']
delivered_count = statuses.count('delivered')  # 3

# Example: Reorder threshold
if statuses.count('out-of-stock') > 2:
    trigger_reorder()
```

## **4. List Modification Functions**

### **`remove()` - Delete by Value**
Removes the first matching item.

```python

# Example: Cleanup expired coupons
```

### **`pop()` - Remove by Index**
Removes and returns item at index (last if no index).

```python

# Use Case: Process orders in order

    next_task = task_queue.pop(0)

```

### **`clear()` - Empty the List**
Removes all items.

```python

temp_items.clear()  # []

# Example: Reset shopping cart

```

## **5. List Organization Functions**

### **`sort()` - In-Place Sorting**
Sorts the list (optionally with key function).


### **`reverse()` - Reverse Order**
Reverses elements in place.


### **`sorted()` - Return New Sorted List**
Returns a new sorted list without modifying original.

