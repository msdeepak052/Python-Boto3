## 🖐 5 Hands-On Exercises — Platform Engineering Use Cases

Real scenarios you'd actually hit as a platform engineer, solved end-to-end so you can see how each data type is used in practice.

### 1. Parse `kubectl get pods` output into structured data

**Scenario:** You run `kubectl get pods` and get raw text back. You need it as structured data to feed into a health-check script or Slack alert.

```python
# Raw line as kubectl would print it (str)
pod_line = "web-app-7f9c8d 1/1 Running 0 3d web01"

fields = pod_line.split()          # str -> list
name, ready, status, restarts, age, node = fields

pod = {                              # list -> dict (structured record)
    "name": name,
    "ready": ready,
    "status": status,
    "restarts": int(restarts),      # str -> int, so we can compare numerically
    "age": age,
    "node": node,
}

print(pod)
# {'name': 'web-app-7f9c8d', 'ready': '1/1', 'status': 'Running',
#  'restarts': 0, 'age': '3d', 'node': 'web01'}

if pod["status"] != "Running" or pod["restarts"] > 3:
    print(f"🔴 Investigate {pod['name']}")
else:
    print(f"✅ {pod['name']} is healthy")
```
**Types used:** `str` → `.split()` → `list` → `dict`, plus `str`→`int` conversion for the restart count comparison.

### 2. Summarize a Terraform plan (`added` / `changed` / `destroyed`)

**Scenario:** Before approving a `terraform apply` in CI, you want a quick automated gate that blocks the pipeline if anything gets destroyed.

```python
# Counts you'd normally scrape from `terraform plan -json`
plan_summary = {"add": 4, "change": 2, "destroy": 1}   # dict of int

total_actions = sum(plan_summary.values())
has_destroy = plan_summary["destroy"] > 0               # bool

print(f"Total resource actions: {total_actions}")
print(f"Contains destructive changes: {has_destroy}")

if has_destroy:
    print("🛑 Blocking auto-apply — needs manual approval")
else:
    print("✅ Safe to auto-apply")
```
**Types used:** `dict` for the summary, `int` values, a `bool` flag driving the decision — this is exactly the shape of a CI approval gate.

### 3. Validate environment variables before a service starts

**Scenario:** Your app reads config from environment variables (always strings). Before starting the service, you validate and convert them to the right type — a very common platform-eng bug source is forgetting env vars are always `str`.

```python
# os.environ.get() always returns a string (or None if missing)
raw_env = {
    "MAX_CONNECTIONS": "100",
    "TIMEOUT_SECONDS": "2.5",
    "DEBUG": "true",
    "REGION": "us-west-2",
    "API_KEY": None,          # missing / not set
}

max_connections = int(raw_env["MAX_CONNECTIONS"])     # str -> int
timeout = float(raw_env["TIMEOUT_SECONDS"])            # str -> float
debug = raw_env["DEBUG"].lower() == "true"              # str -> bool

print(max_connections, type(max_connections))   # 100 <class 'int'>
print(timeout, type(timeout))                    # 2.5 <class 'float'>
print(debug, type(debug))                        # True <class 'bool'>

if raw_env["API_KEY"] is None:                    # NoneType check
    print("🔴 API_KEY missing — refusing to start service")
```
**Types used:** every env var starts as `str`/`None` — this is the classic real-world reason to know `int()`, `float()`, and `None` checks cold.

### 4. De-duplicate node names collected from multiple clusters

**Scenario:** You pull node lists from three clusters (via `kubectl get nodes` in each context) to build a unique inventory for patching. Some nodes appear in more than one list by mistake (bad automation, stale data).

```python
cluster_a = ["node-1", "node-2", "node-3"]
cluster_b = ["node-3", "node-4"]
cluster_c = ["node-2", "node-5"]

all_nodes = cluster_a + cluster_b + cluster_c    # list, keeps duplicates
unique_nodes = set(all_nodes)                     # set removes duplicates automatically

print(f"Raw entries: {len(all_nodes)}")           # 7
print(f"Unique nodes: {len(unique_nodes)}")       # 5
print(sorted(unique_nodes))                        # sorted for a stable, readable list

patch_batch = tuple(sorted(unique_nodes))          # freeze the list into an immutable batch
print(patch_batch)   # tuple — this batch shouldn't change once the patch job starts
```
**Types used:** `list` for raw collection (order + duplicates matter while gathering), `set` to dedupe, `tuple` to lock the final batch so nothing can accidentally mutate it mid-run.

### 5. Build a CMDB-style service inventory record

**Scenario:** You maintain a small inventory of services for your internal CMDB / catalog. Each record combines almost every data type you've learned.

```python
service_record = {
    "name": "payments-api",                 # str
    "replicas": 3,                          # int
    "cpu_limit_cores": 1.5,                 # float
    "is_critical": True,                    # bool
    "namespace": "prod",                    # str
    "endpoints": ["/health", "/pay", "/refund"],   # list — can grow over time
    "region_az": ("us-west-2a", "us-west-2b"),      # tuple — fixed, shouldn't change
    "on_call_owner": None,                   # NoneType — not assigned yet
    "tags": {"tier1", "payments", "pci"},     # set — no duplicate tags allowed
}

print(f"Service: {service_record['name']} ({service_record['replicas']} replicas)")
print(f"Critical service? {service_record['is_critical']}")
print(f"Owner assigned? {service_record['on_call_owner'] is not None}")

# Add a new endpoint (list is mutable)
service_record["endpoints"].append("/webhook")
print(service_record["endpoints"])   # ['/health', '/pay', '/refund', '/webhook']
```
**Types used:** all 8 core types in one realistic record — this is how you'd actually model infrastructure data in Python.

## 🔢 **1. Numeric Types**

### a) `int` (Integer)

Whole numbers, positive or negative.

```python
x = 10
y = -25
print(type(x))  # <class 'int'>
```

### b) `float` (Floating point number)

Decimal numbers.

```python
pi = 3.1415
salary = 9999.99
print(type(pi))  # <class 'float'>
```

### c) `complex` (Complex numbers)

Numbers with a real and imaginary part.

```python
z = 2 + 3j
print(z.real, z.imag)  # 2.0 3.0
```

---

## 🔤 **2. `str` (String)**

Sequence of characters enclosed in `' '` or `" "`.

```python
name = "Deepak"
greeting = 'Hello!'
print(name.upper())     # DEEPAK
print(greeting[0])      # H
```

---

## ✅ **3. `bool` (Boolean)**

Only two values: `True` or `False`. Often used in conditions.

```python
is_active = True
is_logged_in = False
print(5 > 3)  # True
```

---

## 📦 **4. `list` (Ordered, Mutable Collection)**

Can contain elements of any data type, including other lists.

```python
fruits = ['apple', 'banana', 'cherry']
fruits.append('mango')
print(fruits[1])  # banana
```

We're getting the IndexError: list assignment index out of range because you're trying to assign a value to an index (fruits[4]) that doesn't exist yet in the list.

```python
fruits = ['apple', 'banana', 'cherry']  # Index 0,1,2 → List has 3 items
fruits.append('mango')  # Now list becomes ['apple', 'banana', 'cherry', 'mango'] → Index 3 added

print(fruits[1])  # ✅ 'banana'

fruits[4] = 'orange'  # ❌ Error: Index 4 doesn't exist, so direct assignment fails

# If you want to add 'orange' at the end of the list, use .append():

fruits.append('orange')  # ✅ Correct way to add new item at end
print(fruits[4])         # ✅ This will now work


```

---

## 📚 **5. `tuple` (Ordered, Immutable Collection)**

Similar to lists but **cannot be modified**.

```python
dimensions = (1920, 1080)
print(dimensions[0])  # 1920
```

---

## 🔑 **6. `dict` (Dictionary)**

Key-value pairs. Keys must be unique.

```python
person = {
    "name": "Deepak",
    "age": 30,
    "is_admin": True
}
print(person["name"])  # Deepak
```

---

## 📋 **7. `set` (Unordered, Unique Elements)**

No duplicates, and order is not guaranteed.

```python
colors = {"red", "green", "blue"}
colors.add("red")   # No effect; already exists
print(colors)
```

---

## 🚫 **8. `NoneType`**

Represents the absence of a value.

```python
result = None
print(type(result))  # <class 'NoneType'>
```

### Python Ordered vs Unordered Data Types

| Data Type                  | Ordered? | Mutable? | Allows Duplicates?    | Example                         | Access      |
| -------------------------- | -------- | -------- | --------------------- | -------------------------------- | ----------- |
| **List** `list`            | ✅ Yes    | ✅ Yes    | ✅ Yes                 | `["a", "b", "a"]`               | By index    |
| **Tuple** `tuple`          | ✅ Yes    | ❌ No     | ✅ Yes                 | `("a", "b", "a")`               | By index    |
| **String** `str`           | ✅ Yes    | ❌ No     | ✅ Yes                 | `"hello"`                       | By index    |
| **Dictionary** `dict`      | ✅ Yes*   | ✅ Yes    | ❌ Keys must be unique | `{"name": "Deepak", "age": 30}` | By key      |
| **Set** `set`              | ❌ No     | ✅ Yes    | ❌ No                  | `{"a", "b", "c"}`               | No indexing |
| **Frozen Set** `frozenset` | ❌ No     | ❌ No     | ❌ No                  | `frozenset({"a", "b"})`         | No indexing |

* **Dictionary:** preserves **insertion order** in modern Python (Python 3.7+), but you normally use it as a **key-value mapping**, not like a sequence.

### Examples

```python
# 1. LIST — Ordered
numbers = [10, 20, 30, 20]

print(numbers[0])     # 10
print(numbers)        # [10, 20, 30, 20]
```

```python
# 2. TUPLE — Ordered
numbers = (10, 20, 30, 20)

print(numbers[0])     # 10
print(numbers)        # (10, 20, 30, 20)
```

```python
# 3. STRING — Ordered
name = "Deepak"

print(name[0])        # D
print(name[2])        # e
```

```python
# 4. DICTIONARY — Insertion ordered
user = {
    "name": "Deepak",
    "age": 30,
    "role": "Reader"
}

print(user["name"])   # Deepak
```

```python
# 5. SET — Unordered
numbers = {10, 20, 30, 20}

print(numbers)        # {10, 20, 30}
# Duplicate 20 is automatically removed

# ❌ Cannot do:
# numbers[0]
```

```python
# 6. FROZENSET — Unordered + Immutable
numbers = frozenset([10, 20, 30, 20])

print(numbers)        # frozenset({10, 20, 30})

# ❌ Cannot modify
# numbers.add(40)
```

### Easy way to remember

| **Ordered**                | **Unordered** |
| -------------------------- | ------------- |
| `list` ✅                   | `set` ❌       |
| `tuple` ✅                  | `frozenset` ❌ |
| `str` ✅                    |               |
| `dict` ✅ (insertion order) |               |

**For your Python interview prep, remember this distinction:**
`list → ordered + mutable`
`tuple → ordered + immutable`
`set → unordered + mutable + unique`
`frozenset → unordered + immutable + unique`
`dict → key-value + insertion ordered + mutable`

### ✅ **1. Basic String Info**

| Method                    | Description                        | Example                                           |
| ------------------------- | ---------------------------------- | ------------------------------------------------- |
| `.lower()`                | Converts to lowercase              | `'BOOKSHELF'.lower()` → `'bookshelf'`             |
| `.upper()`                | Converts to uppercase              | `'library'.upper()` → `'LIBRARY'`                 |

| `.strip()`                | Removes whitespace (start & end)   | `'  notes.txt  '.strip()` → `'notes.txt'`         |
| `.lstrip()` / `.rstrip()` | Removes whitespace from left/right | `'   page  '.lstrip()` → `'page  '`               |

print(string1.split())

## 📏 `len()` – Get Length of Strings, Lists, etc.

### ✅ **Syntax:**

```python
len(object)
```

It returns the **number of characters** in a string, or the **number of items** in a list, tuple, dict, etc.

---

### 🧵 **1. For Strings (Character Count)**

```python
book_title = "the-great-gatsby"
print(len(book_title))  # 16
```

✔️ **Use case:**
Check if a title exceeds a display limit (e.g., 63 characters max for a spine label).

---

### 📋 **2. For Lists (Number of Items)**

```python
books = ["Book A", "Book B", "Book C"]
print(len(books))  # 3
```

✔️ **Use case:**
Count the number of items in a list, e.g. books in a basket, for a quick inventory check.

---

### 🧰 **3. For Dictionaries (Number of Keys)**

```python
student = {
    "name": "Aisha",
    "age": 21
}
print(len(student))  # 2
```

✔️ **Use case:**
Validate the number of fields loaded in a record.

---

### 📁 **4. For Files (Check Length of Each Line)**

```python
message = "Please return the book to the library today"
if len(message) > 30:
    print("Trim or wrap the line")
```

✔️ **Use case:**
Detect and clean long lines of text before saving to a file.
