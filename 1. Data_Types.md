## 🖐 5 Hands-On Exercises — Platform Engineering Use Cases

Real scenarios you'd actually hit as a platform engineer, solved end-to-end so you can see how each data type is used in practice. Read the scenario, look at the solution, then try changing the input yourself to test your understanding.

### 1. Parse `kubectl get pods` output into structured data

**Scenario:** You run `kubectl get pods` and get raw text back. You need it as structured data to feed into a health-check script or Slack alert.

```python
# Raw line as kubectl would print it (str)
pod_line = "web-app-7f9c8d 1/1 Running 0 3d web01"

fields = pod_line.split()          # str -> list
name, ready, status, restarts, age, node = fields

pod = {                              # list -> dict (structured record)
    "name": name,
    "ready": ready,
    "status": status,
    "restarts": int(restarts),      # str -> int, so we can compare numerically
    "age": age,
    "node": node,
}

print(pod)
# {'name': 'web-app-7f9c8d', 'ready': '1/1', 'status': 'Running',
#  'restarts': 0, 'age': '3d', 'node': 'web01'}

if pod["status"] != "Running" or pod["restarts"] > 3:
    print(f"🔴 Investigate {pod['name']}")
else:
    print(f"✅ {pod['name']} is healthy")
```
**Types used:** `str` → `.split()` → `list` → `dict`, plus `str`→`int` conversion for the restart count comparison.

### 2. Summarize a Terraform plan (`added` / `changed` / `destroyed`)

**Scenario:** Before approving a `terraform apply` in CI, you want a quick automated gate that blocks the pipeline if anything gets destroyed.

```python
# Counts you'd normally scrape from `terraform plan -json`
plan_summary = {"add": 4, "change": 2, "destroy": 1}   # dict of int

total_actions = sum(plan_summary.values())
has_destroy = plan_summary["destroy"] > 0               # bool

print(f"Total resource actions: {total_actions}")
print(f"Contains destructive changes: {has_destroy}")

if has_destroy:
    print("🛑 Blocking auto-apply — needs manual approval")
else:
    print("✅ Safe to auto-apply")
```
**Types used:** `dict` for the summary, `int` values, a `bool` flag driving the decision — this is exactly the shape of a CI approval gate.

### 3. Validate environment variables before a service starts

**Scenario:** Your app reads config from environment variables (always strings). Before starting the service, you validate and convert them to the right type — a very common platform-eng bug source is forgetting env vars are always `str`.

```python
# os.environ.get() always returns a string (or None if missing)
raw_env = {
    "MAX_CONNECTIONS": "100",
    "TIMEOUT_SECONDS": "2.5",
    "DEBUG": "true",
    "REGION": "us-west-2",
    "API_KEY": None,          # missing / not set
}

max_connections = int(raw_env["MAX_CONNECTIONS"])     # str -> int
timeout = float(raw_env["TIMEOUT_SECONDS"])            # str -> float
debug = raw_env["DEBUG"].lower() == "true"              # str -> bool

print(max_connections, type(max_connections))   # 100 <class 'int'>
print(timeout, type(timeout))                    # 2.5 <class 'float'>
print(debug, type(debug))                        # True <class 'bool'>

if raw_env["API_KEY"] is None:                    # NoneType check
    print("🔴 API_KEY missing — refusing to start service")
```
**Types used:** every env var starts as `str`/`None` — this is the classic real-world reason to know `int()`, `float()`, and `None` checks cold.

### 4. De-duplicate node names collected from multiple clusters

**Scenario:** You pull node lists from three clusters (via `kubectl get nodes` in each context) to build a unique inventory for patching. Some nodes appear in more than one list by mistake (bad automation, stale data).

```python
cluster_a = ["node-1", "node-2", "node-3"]
cluster_b = ["node-3", "node-4"]
cluster_c = ["node-2", "node-5"]

all_nodes = cluster_a + cluster_b + cluster_c    # list, keeps duplicates
unique_nodes = set(all_nodes)                     # set removes duplicates automatically

print(f"Raw entries: {len(all_nodes)}")           # 7
print(f"Unique nodes: {len(unique_nodes)}")       # 5
print(sorted(unique_nodes))                        # sorted for a stable, readable list

patch_batch = tuple(sorted(unique_nodes))          # freeze the list into an immutable batch
print(patch_batch)   # tuple — this batch shouldn't change once the patch job starts
```
**Types used:** `list` for raw collection (order + duplicates matter while gathering), `set` to dedupe, `tuple` to lock the final batch so nothing can accidentally mutate it mid-run.

### 5. Build a CMDB-style service inventory record

**Scenario:** You maintain a small inventory of services for your internal CMDB / catalog. Each record combines almost every data type you've learned.

```python
service_record = {
    "name": "payments-api",                 # str
    "replicas": 3,                          # int
    "cpu_limit_cores": 1.5,                 # float
    "is_critical": True,                    # bool
    "namespace": "prod",                    # str
    "endpoints": ["/health", "/pay", "/refund"],   # list — can grow over time
    "region_az": ("us-west-2a", "us-west-2b"),      # tuple — fixed, shouldn't change
    "on_call_owner": None,                   # NoneType — not assigned yet
    "tags": {"tier1", "payments", "pci"},     # set — no duplicate tags allowed
}

print(f"Service: {service_record['name']} ({service_record['replicas']} replicas)")
print(f"Critical service? {service_record['is_critical']}")
print(f"Owner assigned? {service_record['on_call_owner'] is not None}")

# Add a new endpoint (list is mutable)
service_record["endpoints"].append("/webhook")
print(service_record["endpoints"])   # ['/health', '/pay', '/refund', '/webhook']
```
**Types used:** all 8 core types in one realistic record — this is how you'd actually model infrastructure data in Python.

## 🔢 1. Numeric Types

- `int` → whole numbers (positive/negative), no decimal point
- `float` → numbers with a decimal point
- `complex` → has a real and imaginary part (`a + bj`), rarely needed for beginners

```python
x = 10          # int
pi = 3.1415     # float
z = 2 + 3j      # complex

print(type(x))    # <class 'int'>
print(type(pi))   # <class 'float'>
print(z.real, z.imag)   # 2.0 3.0
```

---

## 🔤 2. `str` (String)

- A sequence of characters, written in `' '` or `" "`
- Each character has a position (index), starting from `0`
- Strings are **immutable** — methods return a *new* string, they don't change the original

```python
name = "Deepak"
greeting = 'Hello!'

print(name.upper())   # DEEPAK
print(greeting[0])    # H
```

See the [full string methods reference](#-string-methods-reference) below for all common methods with examples.

---

## ✅ 3. `bool` (Boolean)

- Only two possible values: `True` or `False`
- Used for conditions (`if`, `while`) and comparisons

```python
is_active = True
is_logged_in = False

print(5 > 3)   # True
```

---

## 📦 4. `list` (Ordered, Mutable)

- Written with `[ ]`
- Keeps insertion order, allows duplicates, can hold mixed data types
- **Mutable** → you can change, add, or remove items after creation

```python
fruits = ['apple', 'banana', 'cherry']
fruits.append('mango')
print(fruits[1])   # banana
```

⚠️ **Common mistake:** you can't assign to an index that doesn't exist yet.

```python
fruits = ['apple', 'banana', 'cherry']   # indexes 0,1,2

fruits[4] = 'orange'    # ❌ IndexError: index 4 doesn't exist

fruits.append('orange')  # ✅ correct way to add at the end
print(fruits[3])         # orange
```

## 📚 5. `tuple` (Ordered, Immutable)

- Written with `( )`
- Same as a list, but **cannot be changed** once created — safer for fixed data (e.g. coordinates, constants)

```python
dimensions = (1920, 1080)
print(dimensions[0])   # 1920
```

---

## 🔑 6. `dict` (Key-Value Pairs)

- Written with `{ key: value }`
- Keys must be **unique**; values can be anything
- Access values by key, not by position
- Preserves insertion order (Python 3.7+)

```python
person = {
    "name": "Deepak",
    "age": 30,
    "is_admin": True
}
print(person["name"])   # Deepak
```

---

## 📋 7. `set` and `frozenset` (Unique, Unordered)

- `set` → written with `{ }`, automatically removes duplicates, **no indexing**, mutable
- `frozenset` → same as `set` but **immutable** (can't add/remove after creation)

```python
colors = {"red", "green", "blue"}
colors.add("red")     # no effect, already exists
print(colors)

numbers = frozenset([10, 20, 30, 20])
print(numbers)         # frozenset({10, 20, 30}) — duplicate removed
# numbers.add(40)      # ❌ Error: frozenset can't be modified
```

---

## 🚫 8. `NoneType`

- `None` represents "no value" or "empty" — Python's version of null
- Often used as a default/placeholder before a real value is assigned

```python
result = None
print(type(result))   # <class 'NoneType'>
```

## 📊 Ordered vs Unordered — Cheat Sheet

| Data Type   | Ordered? | Mutable? | Duplicates? | Access      |
| ----------- | -------- | -------- | ----------- | ----------- |
| `list`      | ✅        | ✅        | ✅           | by index    |
| `tuple`     | ✅        | ❌        | ✅           | by index    |
| `str`       | ✅        | ❌        | ✅           | by index    |
| `dict`      | ✅*       | ✅        | ❌ (keys)    | by key      |
| `set`       | ❌        | ✅        | ❌           | no indexing |
| `frozenset` | ❌        | ❌        | ❌           | no indexing |

\* dict preserves **insertion order**, but you should still treat it as a key→value mapping, not a sequence.

**Quick memory trick:**
`list → ordered + mutable` · `tuple → ordered + immutable` · `set → unordered + mutable + unique` · `frozenset → unordered + immutable + unique` · `dict → key-value + insertion ordered`

```python
numbers = {10, 20, 30, 20}
print(numbers)     # {10, 20, 30} — duplicate auto-removed, order not guaranteed
# numbers[0]        ❌ sets have no index
```

## 🧪 Type Checking & Conversion

- `type(x)` tells you the current type
- `float()`, `int()`, `str()` convert between types

```python
x = 5
print(type(x))       # <class 'int'>

y = float(x)          # int → float
print(y, type(y))     # 5.0 <class 'float'>

z = int("123")         # string → int
print(z, type(z))      # 123 <class 'int'>
```

## 🧵 String Methods Reference

Strings are the type you'll use methods on the most — here's the full toolkit in one place.

### Case & Cleanup

| Method                     | What it does                | Example                                        |
| -------------------------- | ---------------------------- | ----------------------------------------------- |
| `.lower()`                 | to lowercase                 | `'HOSTNAME'.lower()` → `'hostname'`             |
| `.upper()`                 | to UPPERCASE                 | `'devops'.upper()` → `'DEVOPS'`                 |
| `.capitalize()`             | capitalize first letter only | `'server down'.capitalize()` → `'Server down'`  |
| `.title()`                  | capitalize every word        | `'disk space full'.title()` → `'Disk Space Full'` |
| `.strip()`                  | remove spaces from both ends | `'  log.txt  '.strip()` → `'log.txt'`           |
| `.lstrip()` / `.rstrip()`  | remove spaces left/right only| `'   file  '.lstrip()` → `'file  '`             |

### Search & Match

| Method                | What it does                          | Example                                           |
| ---------------------- | -------------------------------------- | -------------------------------------------------- |
| `.startswith('x')`     | does it start with `x`?                | `'ERROR: Disk full'.startswith('ERROR')` → `True` |
| `.endswith('x')`       | does it end with `x`?                  | `'report.log'.endswith('.log')` → `True`          |
| `.find('x')`           | index of first match, `-1` if missing  | `'backup failed'.find('fail')` → `7`              |
| `.count('x')`          | how many times `x` appears             | `'abc abc abc'.count('abc')` → `3`                |
| `'x' in string`        | is `x` present at all?                 | `'ERROR' in log_line`                             |

### Replace, Split, Join

| Method                | What it does           | Example                                                        |
| ---------------------- | ------------------------ | ----------------------------------------------------------------- |
| `.replace(old, new)`   | replace all occurrences  | `'prod-server'.replace('prod', 'dev')` → `'dev-server'`         |
| `.split('x')`          | string → list, split at `x` | `'10.0.0.1,10.0.0.2'.split(',')` → `['10.0.0.1', '10.0.0.2']` |
| `'x'.join(list)`       | list → string, joined by `x` | `','.join(['a', 'b'])` → `'a,b'`                              |

### Validation Checks (return `True`/`False`)

| Method         | Checks for       | Example                       |
| --------------- | ----------------- | ------------------------------- |
| `.isalpha()`    | letters only      | `'abc'.isalpha()` → `True`     |
| `.isdigit()`    | digits only       | `'1234'.isdigit()` → `True`    |
| `.isalnum()`    | letters + digits  | `'abc123'.isalnum()` → `True`  |
| `.isspace()`    | whitespace only   | `'   '.isspace()` → `True`     |
| `.isupper()` / `.islower()` | all upper/lower | `'CMD'.isupper()` → `True` |

### Formatting

| Method       | What it does                       | Example                        |
| ------------- | ------------------------------------ | --------------------------------- |
| `f"{var}"`    | f-string — insert a variable (recommended) | `f"User: {user}"`         |
| `.format()`   | older way to insert values           | `"Server: {}".format('web01')` |
| `.zfill(n)`   | pad number with leading zeros        | `'7'.zfill(3)` → `'007'`         |

### Putting it together — real examples

```python
s = "Hello Folks, I am Deepak Yadav from India. I love DevOps and Shell Scripting."

print(s.lower())                       # all lowercase
print(s.title())                       # Title Case Every Word
print(s.replace("DevOps", "Python"))   # swap a word
print(s.split())                       # split into a list of words
print(s.split(","))                    # split at commas
```

```python
# extracting an IP address from a log line
line = "Connected from 10.0.0.7 to port 22"
ip = line.split()[2]
print(ip)   # 10.0.0.7
```

```python
# checking if a line is an error, and reacting to it
log = "ERROR: Disk quota exceeded"
if log.startswith("ERROR"):
    print("🔴 Log is an error")
```

```python
# swapping environment name in a command
cmd = "kubectl apply -f prod.yaml"
print(cmd.replace("prod", "dev"))   # kubectl apply -f dev.yaml
```

## 📏 `len()` — works on strings, lists, dicts, tuples

`len(object)` returns the number of characters (string) or items (list/tuple/dict/set).

```python
print(len("my-s3-bucket"))               # 12 → characters
print(len(["i-001", "i-002", "i-003"]))   # 3  → items
print(len({"DB_HOST": "localhost", "DB_PORT": "5432"}))  # 2 → key-value pairs
```

**Practical use:** check if a name is too long, count items in a list, or validate that a config has the expected number of keys.
