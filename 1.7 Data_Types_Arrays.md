## 🖐 5 Hands-On Exercises — Platform Engineering Use Cases

Real scenarios solved end-to-end so you can see the `array` module used the way you'd actually use it on the job.

### 1. Stream a metrics log file and alert on average threshold

**Scenario:** A log file has one CPU% reading per line; you want a memory-efficient way to load thousands of readings and check the average.

```python
import array

readings = array.array('i')   # 'i' = signed int
with open('metrics.log') as f:
    for line in f:
        readings.append(int(line.strip()))

avg = sum(readings) / len(readings)
print(f"Average CPU: {avg:.1f}%")

if avg > 80:
    print("⚠️ Alert: sustained high CPU usage")
```
**Why it matters:** `array('i', ...)` stores raw integers far more compactly than a `list` of Python `int` objects — worth it once you're loading large metric files repeatedly.

---

### 2. Compare memory usage: array vs list

**Scenario:** You're deciding whether it's worth switching a large numeric buffer from `list` to `array` in a memory-constrained script (e.g. running in a small container).

```python
import sys
from array import array

numbers = list(range(1000))
typed_numbers = array('i', range(1000))

print(f"list memory: {sys.getsizeof(numbers)} bytes")
print(f"array memory: {sys.getsizeof(typed_numbers)} bytes")
# array is significantly smaller — no per-element Python object overhead
```
**Why it matters:** in memory-limited environments (small containers, embedded agents), `array` can meaningfully cut memory footprint for large numeric datasets.

---

### 3. Pre-allocate a fixed-size buffer for incoming binary data

**Scenario:** You're writing a small agent that reads a fixed-size binary payload from a socket.

```python
from array import array

buf = array('B', [0] * 256)          # 'B' = unsigned char, 256-byte buffer
buf[0:4] = array('B', [0xDE, 0xAD, 0xBE, 0xEF])   # simulate writing received bytes

print(buf[:4])   # array('B', [222, 173, 190, 239])
```
**Why it matters:** pre-allocating a fixed buffer avoids repeated resizing — the same pattern used in low-level network/agent code.

---

### 4. Send numeric data over a socket as raw bytes

**Scenario:** A lightweight monitoring agent needs to transmit a batch of integer readings efficiently instead of JSON-encoding them.

```python
from array import array

data = array('i', [10, 20, 30, 40])
payload = data.tobytes()          # convert to raw bytes for sending
# sock.send(payload)

# On the receiving end:
received = array('i')
received.frombytes(payload)        # convert back from raw bytes
print(list(received))                # [10, 20, 30, 40]
```
**Why it matters:** `.tobytes()` / `.frombytes()` is far more compact than JSON for numeric payloads — relevant for high-frequency metrics shipping.

---

### 5. Model a small per-node metrics grid

**Scenario:** You track one array of readings per node, and want to access a specific node's specific reading.

```python
from array import array

node1_cpu = array('i', [40, 55, 60])   # readings over time for node1
node2_cpu = array('i', [30, 45, 50])

grid = [node1_cpu, node2_cpu]           # plain list holding multiple typed arrays
print(grid[0][1])   # 55 — node1's second reading
```
**Why it matters:** `array` is strictly 1-D, so multi-node/multi-dimensional data is modeled as a regular `list` of arrays — good enough for small grids; reach for NumPy once this gets large or needs real matrix math.

## 🧰 1. What is a Python Array?

* Provided by the built‑in **`array`** module, arrays are **homogeneous**, memory‑efficient sequences—unlike Python lists, which can hold mixed types and have higher per‑element overhead. ([GeeksforGeeks][1])
* Internally, elements are stored in **contiguous memory**, enabling fast (O(1)) index access. ([GeeksforGeeks][1])

Arrays are ideal when you need to store large sequences of numbers (e.g., temperature readings, exam scores, measurements) efficiently without pulling in NumPy—especially in lightweight scripts or simple programs.

## ✍️ 2. Declaring and Creating Arrays

```python
import array as arr

# Syntax: array(typecode, iterable)
a = arr.array('i', [15, 18, 21, 19, 16])   # 5 days of temperature readings (°C)
```

* **`typecode`** defines the data type & size (see table below).
* All elements must share the same type. ([GeeksforGeeks][1])

**Common typecodes:**

| Typecode | C-type             | Python type | Size (bytes) |
| -------- | ------------------- | ----------- | ------------- |
| `'b'`    | signed char        | `int`       | 1            |
| `'B'`    | unsigned char      | `int`       | 1            |
| `'h'`    | signed short       | `int`       | 2            |
| `'H'`    | unsigned short     | `int`       | 2            |
| `'i'`    | signed int         | `int`       | 2            |
| `'I'`    | unsigned int       | `int`       | 2            |
| `'l'`    | signed long        | `int`       | 4            |
| `'L'`    | unsigned long      | `int`       | 4            |
| `'q'`    | signed long long   | `int`       | 8            |
| `'Q'`    | unsigned long long | `int`       | 8            |
| `'f'`    | float              | `float`     | 4            |
| `'d'`    | double             | `float`     | 8            |

([GeeksforGeeks][2])

## 📥 3. Accessing Items

```python
print(a[0])   # 15 — first day's reading
print(a[-1])  # 16 — last day's reading via negative indexing
```

* O(1) random access due to contiguous layout. ([GeeksforGeeks][2])

---

## ➕ 4. Adding Elements

### `.append()`

```python
a.append(20)   # add today's reading to the end
```

* Efficient: O(1).&#x20;

### `.insert(i, x)`

```python
a.insert(2, 17)  # insert a reading of 17 at index 2
```

* O(n) because elements may shift. ([GeeksforGeeks][3])

---

## 🗑️ 5. Removing Elements

* `.pop([i])` – removes and returns by index (default end).
* `.remove(x)` – removes first occurrence of `x`.
  Both operations have O(n) in worst-case for shifting. ([GeeksforGeeks][4], [GeeksforGeeks][3])

## 🧩 7. Multidimensional Arrays

Though `array` is 1‑D, you can nest arrays:

```python
from array import array

day1 = array('i', [15, 18, 21])
day2 = array('i', [14, 17, 20])

readings = [day1, day2]  # Use a regular list to hold arrays
print(readings)
print(readings[0][1])  # Access element at day 0, reading 1 → 18

```

## 📊 8. Arrays vs Lists vs NumPy

* **Lists**: dynamic, heterogeneous, slower per-element, flexible.
* **`array.array`**: homogeneous, efficient, lower-level methods. ([Wikipedia][7])
* **NumPy `ndarray`**: multi-dimensional, powerful vector operations, linear algebra support, but heavier and requires external dependency.&#x20;

**Choose based on needs**: simple, typed arrays → `array`; heavy math → NumPy.

## ✅ Summary

* **`array`** from `array` module: typed, memory‑efficient, ideal for simple numeric sequences.
* **Op types** include creation, indexing, append, insert, remove, pop, reverse, index, count.
* **Performance**: Access O(1), append O(1), insert/remove O(n).
* **Alternatives**:

  * Use **lists** for mixed types and flexibility.
  * Use **NumPy arrays** for vectorized ops, matrices, numeric libraries.

---

## 📚 Integration Tips

* Use typed arrays for reading/writing binary files, counters, or buffer management.
* In small or resource-constrained environments, `array` avoids pulling in heavy dependencies.
* For larger datasets and real numeric analysis, switch to NumPy when data size grows or precision/vectorized math matters.
